# Contributing to Multimodal Fake News Detection

Thank you for your interest in contributing to this project.

## How to Contribute

1. Fork the repository and create a focused branch for your change.
2. Keep pull requests small and specific (bug fix, model improvement, docs update, or UI enhancement).
3. Include a clear description of:
   - What changed
   - Why it changed
   - How it was tested
4. For research/model contributions, include reproducibility notes (dataset split, metrics, and configuration).

## Suggested Contribution Areas

- Model benchmarking and evaluation improvements
- Dataset quality checks and multilingual analysis
- Explainability and confidence calibration enhancements
- Frontend UX and accessibility improvements
- Documentation, quickstarts, and tutorial examples

## Trust & Quality Expectations

- Be respectful and constructive in issues and pull requests.
- Add or update documentation when behavior changes.
- Avoid committing secrets or private credentials.
- Validate your changes locally before opening a PR.

## Discussions, Issues, and Reviews

- Use issues for bugs, roadmap proposals, and research ideas.
- Use pull requests for implementation.
- Use the in-app `About > User Reviews` tab to share practical platform feedback.
